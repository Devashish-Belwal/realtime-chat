# Realtime Chat

A small real-time chat application built to learn WebSockets with Bun, Express, and React.

## Milestone 4 — Docker Hub

Images: `devashishbelwal/realtime-chat-client:latest` / `devashishbelwal/realtime-chat-server:latest` (and `<commit-sha>` tags). Build: `docker build -f apps/client/Dockerfile -t devashishbelwal/realtime-chat-client .` / `docker build -f apps/server/Dockerfile -t devashishbelwal/realtime-chat-server .`. Push: `docker push devashishbelwal/realtime-chat-client:latest` etc.
